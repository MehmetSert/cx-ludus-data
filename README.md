# cx-ludus-data

Public release data read at runtime by the cx-ludus CLI. Keeping it outside the
CLI means a new SAP Composable Storefront (Spartacus) release needs no CLI update.

All data is derived from public sources: help.sap.com and the public
[SAP/spartacus](https://github.com/SAP/spartacus) Git tags.

## Files

- `releases.json` — generated by the cx-ludus indexer; do not edit by hand.
  Lists every 221121.x release with its SAP-defined predecessor, the version to
  put in `package.json` (always with `~`), the Git tag used for code diffs, the
  help.sap.com page and the validity dates. `schemaVersion` changes only on
  breaking format changes.
- `releases.overrides.json` — hand-maintained corrections, keyed by release id.
  Any field set here wins over what the indexer parsed. Use it when help.sap.com
  wording changes or omits a value.

Changes arrive as pull requests from the indexer workflow; review the diff before
merging.
